# 78 анимированных клипов — African Penguin

Источник: `../images/manifest.json` (78 кадров, включая 4 перегенерированных
после правок — 0_42, 1_17, 1_24, 8_10 — уже без иглу и без домиков).
Модель — `kling3_0_turbo` (Higgsfield), image-to-video по стартовому кадру,
7 секунд, 1080p, 16:9.

Стоимость: 78 × 14 кредитов = **1092 кредита**. Баланс до старта — 1107.5,
после — 15.5. Ровно в бюджет, как и предупреждал перед запуском.

## Темп движения

По просьбе — два режима, прописаны в `../animation_prompts.json`:

**sharp (20 клипов)** — резко, реальное время, без замедления: резкие
повороты, рывки, хватание/щёлканье клювом, скачки, внезапная смена
направления. Все сцены с чайкой (1:52, 1:59, 2:06, 5:15, 5:22), с мангустом
(3:30, 3:37, 3:44), вся охота/ловля рыбы и все сцены в воде (0:35, 4:33,
4:40, 7:00–7:42, 8:38, 8:52).

**gentle (58 клипов)** — лёгкое кинематографичное замедление по умолчанию:
кормление, вылупление, портреты, пейзажи, нежные моменты.

## Технические сбои при генерации (все исправлены без потери кадров)

- **Перехват пресетом.** Higgsfield несколько раз подменял отправку
  автопредложением пресета («IN THE DARK», «DROWN IN MUSIC») вместо
  реальной генерации — решается параметром `declined_preset_id`. Задело
  кадры 1, 3, 4, 9, 26, 54 — все пересланы успешно.
- **Кратковременная нехватка кредитов.** Кадр 72 не прошёл при первой
  отправке — баланс на секунду просел из-за параллельной отправки
  остальных 5 клипов последнего батча. Кредиты не списались, отправлен
  повторно после того как остальные клипы освободили баланс.

`manifest.json` / `urls.tsv` — таймкод, имя, категория темпа, ссылка.
`download.bat` — скачивает все 78 .mp4 в `mp4/` (Windows, PowerShell,
curl не нужен).
