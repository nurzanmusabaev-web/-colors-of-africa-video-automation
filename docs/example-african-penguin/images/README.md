# 78 кадров-раскадровки — African Penguin

Источник: `../storyboard.md` + `../prompts.json`. Модель — `nano_banana_pro`
(Higgsfield, flat 2 credits/кадр на 2K), 16:9, разрешение 2752×1536.

По просьбе — все кадры яркие/солнечные (`bright` в `style`), кроме пяти
специально «золотых» переходов на закате/рассвете (`golden`, timecodes
3:51, 5:29, 8:24, 8:59) и одного подводного (`underwater`, 7:21) — везде
насыщенный, не тусклый свет. Каждый промпт собран из конкретной сцены
`storyboard.md` для этого таймкода + anatomy-lock нужной стадии роста
(взрослый / птенец-пух / линяющий / ювенильный), без общих «случайных»
описаний.

`manifest.json` / `urls.tsv` — таймкод, имя кадра, стиль, job_id, ссылка.
`download.bat` — скачивает все 78 PNG в `frames/` (Windows, нужен curl.exe,
идёт в комплекте с Windows 10/11).

## Проверено при генерации

- Все 78 job'ов завершились `completed`, отказов и возвратов кредитов не было.
- Таймкоды `prompts.json` побайтово сверены со `storyboard.md` — 78/78 совпадают.
- Anatomy-lock разделён по стадиям, чтобы модель не путала птенца со взрослым
  на соседних кадрах: `CHICK_WET` (только что вылупился) → `CHICK_DOWN`
  (несколько недель) → `CHICK_PATCHING` (начало линьки) → `MOLTING`
  (клочья пуха, проступает оперение) → `JUVENILE` (сине-серый, без чёрной
  повязки) → `ADULT` (полное оперение, ближе к финалу — по той же
  конвенции сжатия времени, что и в секретаре: за экранные ~9 минут птенец
  «дорастает» до практически взрослого облика).
