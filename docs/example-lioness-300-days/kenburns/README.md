# Наезды на 65 статичных кадрах

Превращает кадры 5120x2880 в клипы 1920x1080 по 7 секунд с движением камеры.

```bash
bash build-kenburns.sh ../lioness-frames
```

Результат — `kb-clips/0_42.mp4` и так далее, те же имена по таймкодам, что и у
анимированных клипов. Скрипт возобновляемый: при обрыве запусти ещё раз.

## Какое движение куда

| Движение | Кадров | Куда назначено |
|---|---|---|
| `in` — наезд | 23 | макро, морды, глаза, зубы, лапы, пятна |
| `out` — отъезд | 6 | общие планы, горизонт, пустые пространства |
| `drift` — увод вбок | 36 | всё остальное |

Правка вручную — в `moves.tsv`, столбец второй.

## Почему масштаб ограничен 1.22

Кроп не опускается ниже ~4200 пикселей по ширине при выводе в 1920. Запас больше
чем двукратный, поэтому резкость не теряется нигде. Наезд сильнее выглядел бы
эффектнее на глаз, но на макро-кадрах начал бы вылезать шум генерации.

Исходник перед движением поднимается до 7680 по ширине через lanczos — это
убирает дрожание, которым славится `zoompan` на целочисленных координатах.
