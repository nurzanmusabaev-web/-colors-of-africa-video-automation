# Превью: 3 концепции, 6 кадров

Модель `nano_banana_pro` через Higgsfield (2K, 2 кредита за кадр). Текст запечён.

Этот ролик другого жанра, чем львица или секретарь — не угроза/действие, а
«дыхание красоты». Ставка на факты из транскрипта, не на конфликт.

| | Текст | Идея | Ставка |
|---|---|---|---|
| A1, A2 | `PARADISE IS REAL` / `115 ISLANDS` | гранитные валуны и бирюзовая вода — открыточный кадр Сейшел | **высокая** |
| B1, B2 | `200 YEARS OLD` / `OLDER THAN YOU THINK` | морда черепахи Альдабры крупно / целиком в зелени | средняя |
| C1, C2 | `THE STRANGEST SEED ON EARTH` / `PARADISE BENEATH` | Coco de Mer макро / черепаха над рифом под водой | средняя |

## Почему A

Заголовок ролика уже обещает «самый красивый рай на Земле» — превью должно
подтверждать это визуально в первую секунду, не спорить с ним. Гранитные
валуны Anse Source d'Argent — самый узнаваемый образ Сейшел в принципе,
работает на автомате даже без текста.

B и C держат конкретные факты (черепаха старше Гражданской войны в США,
семя весом 30 кг) — вторая линия, если ставка на красоту не пойдёт.
