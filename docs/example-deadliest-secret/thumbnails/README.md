# Превью: 3 концепции, 6 кадров

Модель `nano_banana_pro` через Higgsfield (2K, 2 кредита за кадр). Текст запечён.

Это чужой ролик — ни сценария, ни исходных кадров у меня нет. Прочитал транскрипт
(`../seo-description.txt` собран из него), концепции построены на реальном
содержании: Secret Seven, циветта и парфюм, ночное зрение львов, Млечный Путь.

| | Текст | Идея | Ставка |
|---|---|---|---|
| A1, A2 | `WATCHING YOU` / `AFRICA AT NIGHT` | светящиеся в темноте глаза, ничего больше | **высокая** |
| B1, B2 | `THE SECRET SEVEN` / `AFRICA'S SECRET` | циветта на фоне Млечного Пути / широкий кадр саванны под звёздами | средняя |
| C1, C2 | `FEARS NOTHING` / `NEVER SEEN` | медоед оскалился / панголин свернулся | средняя |

## Почему A

Глаза в кромешной тьме — с большим отрывом самый проверенный крючок в нише
ночных животных: минимум деталей, максимум вопроса «что это». Текущее живое
превью этого не делает и видно по 31 просмотру за три месяца.

B и C держат конкретные факты из транскрипта (циветта = духи, медоед атакует
львиный прайд) — они работают как вторая линия, если A не подойдёт по тону.

## Что не так с текущим описанием на YouTube

- Категория **Travel & Events** вместо **Pets & Animals** (та же ошибка, что
  была у львицы)
- Больше сотни хештегов свалено в тело описания — YouTube всё равно
  индексирует только первые ~15, остальное шум
- Глав не было вообще

Новый `seo-description.txt` со сценарными таймкодами (не оценка — они взяты
прямо из транскрипта) готов к вставке.

## Перед загрузкой
