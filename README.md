# Colors of Africa — автоматизация длинных видео

Пайплайн от темы до готового черновика на YouTube: угол подачи → заголовок со
скорингом → сценарий → озвучка → подбор футажа → рендер → превью → описание →
выгрузка → разбор аналитики.

## Зачем это устроено именно так

Данные канала на 27.07.2026 (38.7k подписчиков, 57.4M просмотров, 134 видео):

| Формат | Просмотров за 2026 |
|---|---|
| Шортсы | 9 279 471 |
| Длинные | **377** |

Разница не в длине и не в качестве съёмки. Разница в упаковке:

- Взлетевшие шортсы: `BUFFALO VS LIONS` (12.5M), `IMPOSSIBLE BATTLE` (24.0M) —
  конкретные виды + конфликт + непредсказуемый исход.
- Провалившиеся длинные: `Baobabs Trees That Remember Dinosaurs` (107),
  `Coffee. How Africa Gave the World a Morning Ritual` (94),
  `Seychelles Wildlife & Nature in the Most Beautiful Paradise on Earth` (224) —
  описательные заголовки без конфликта.

Поэтому стадия упаковки — **гейт**: пайплайн физически не даёт начать
производство, пока заголовок не наберёт порог по правилам, выведенным из этих
данных. Скоринг детерминированный (`coa/scoring.py`), не LLM: гейт должен давать
один и тот же ответ на один и тот же заголовок.

Проверить логику на реальных заголовках канала:

```bash
python3 tests/test_scoring.py
```

Тест утверждает, что все пять фактически провалившихся заголовков скоринг
отклоняет, а формулировки в духе выстреливших шортсов — пропускает.

## Установка

```bash
pip install -r requirements.txt
apt install ffmpeg          # или brew install ffmpeg
cp .env.example .env        # заполнить ключи
```

Обязателен только `ANTHROPIC_API_KEY`. Остальное можно добавлять по мере
надобности: без TTS-ключа озвучка синтезируется тишиной нужной длины (пайплайн
прогоняется целиком), без `PEXELS_API_KEY` футаж берётся только из локального
архива.

## Использование

```bash
python3 -m coa.cli new "Buffalo herd that stopped running from lions"
python3 -m coa.cli run <slug>
```

Пайплайн останавливается на гейтах и ждёт решения:

```bash
python3 -m coa.cli status <slug>
python3 -m coa.cli approve <slug> package
python3 -m coa.cli run <slug>            # продолжит с места остановки
```

Полезные флаги `run`:

| Флаг | Что делает |
|---|---|
| `--yes` | проходить гейты автоматически |
| `--dry-run` | не выгружать на YouTube |
| `--from <стадия>` / `--until <стадия>` | прогнать кусок пайплайна |
| `--force` | перезапустить уже выполненные стадии |

Оценить заголовок, не создавая проект:

```bash
python3 -m coa.cli score "Why This Lion Never Attacks a Buffalo Alone"
```

## Стадии

| # | Стадия | Что делает |
|---|---|---|
| 1 | `ideate` | тема → угол подачи с конкретным конфликтом |
| 2 | `package` | 8 заголовков + концепт превью, скоринг, **гейт** |
| 3 | `script` | сценарий по блокам, каждый с открытым вопросом в конце |
| 4 | `voice` | озвучка по сценам, длительность сцены = длина её начитки |
| 5 | `broll` | футаж: локальный архив → сток → заглушка |
| 6 | `assemble` | нормализация клипов, склейка, сведение с озвучкой |
| 7 | `thumbnail` | кадр из самой конфликтной сцены + текст из концепта |
| 8 | `metadata` | описание, теги, тайм-коды из фактических длительностей, **гейт** |
| 9 | `upload` | выгрузка на YouTube приватно + установка превью |
| 10 | `review` | кривая удержания → номер сцены, где уходит зритель |

`package` не проходит порог за 3 попытки — стадия падает с разбором. Модели на
каждой итерации скармливаются ровно те причины, по которым скоринг снял баллы.

Стадия `review` замыкает цикл: находит самый резкий обрыв удержания и переводит
его обратно в конкретную сцену сценария.

## Структура архива футажа

Подбор идёт по именам файлов и папок — размечать отдельно ничего не нужно:

```
footage/
  lions/
    lion-charge-dust-01.mp4
    lioness-stalking-grass-02.mp4
  buffalo/
    buffalo-herd-standoff-01.mp4
```

Сцена с ключевыми словами `["lion", "charge"]` найдёт первый файл. Индекс
кэшируется в `footage/.coa-index.json`; после пополнения архива достаточно
удалить кэш.

## Что настраивается

Всё в `channel/profile.yaml`: список видов, чёрный список слов в заголовке,
целевая длительность, число блоков, разрешение, параметры выгрузки. Пороги —
в `.env` (`COA_MIN_PACKAGING_SCORE`).

## Что пайплайн намеренно не делает

- **Не публикует.** Выгрузка всегда приватная, публикацию делает человек.
- **Не генерирует видео нейросетью.** Источник кадров — реальный футаж.
- **Не оценивает заголовок через LLM.** Скоринг детерминированный.

## Тесты

```bash
python3 tests/test_scoring.py         # скоринг на реальных заголовках канала
python3 tests/test_media_pipeline.py  # сквозной прогон монтажа (нужен ffmpeg)
```

`test_media_pipeline.py` работает без сети и без ключей: собирает синтетические
клипы, прогоняет `voice → broll → assemble → thumbnail` и проверяет, что длина
видео совпала с озвучкой, футаж подобрался по ключевым словам, а ненайденная
сцена помечена как пропуск.
